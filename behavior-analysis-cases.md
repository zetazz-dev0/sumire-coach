# Behavior Analysis Cases

## Notes

- To reduce privacy exposure, this document keeps only a small number of de-identified examples.
- These examples are not here to prove the framework is correct. They are here to demonstrate how `behavior-analysis-framework.md` can be used to analyze complex, recurring behavior problems.
- Everything below is still a working interpretation. It is suitable for further questioning and revision, not for one-shot certainty.

---

## Case: Chronic Procrastination / Priority Drift

| Field | Content |
| --- | --- |
| Behavior | High-priority tasks keep getting postponed, while the person turns toward things they like more even though those things are relatively lower priority |
| Trigger Context | More likely to activate when facing important work, when an answer is about to be revealed, when ability may be exposed, or when starting would feel like being dominated by the task |
| Basic Dimensions | Mainly `Safety and Threat Avoidance`; secondarily `Anti-Intrusion Boundary` |
| Higher-Order Dimensions | `Exploration and Understanding`, `Autonomous Agency`, `Competence and Efficacy` |
| Reaction Channel(s) | Usually starts with `Fear / Avoidance`; behaviorally it shows up as shifting toward tasks that feel safer, sweeter, and more controllable |
| Source | `mixed` |
| Intensity | Medium to moderately high; not total shutdown, but a redirection of action energy |
| Higher-Order Hijack / Organization | Once the high-priority task gets bound to "Can I actually do this well?", the system becomes more likely to redirect energy into side tasks that immediately provide `Exploration and Understanding`, `Autonomous Agency`, and local `Competence and Efficacy`, making "doing something else" feel both comfortable and falsely productive |
| Basic-Dimension Landing / Lower-Level Hijack | The important task is experienced as a threat to `Safety and Threat Avoidance` and an intrusion upon `Anti-Intrusion Boundary` because it starts to feel dominating; shifting to side tasks functions as an attempt to reduce pressure in the safety layer first |
| Short-Term Gain | Relief, a return of some autonomy, and the feeling of "at least I am not doing nothing" |
| Long-Term Cost | What really matters keeps getting delayed, core anxiety never gets addressed, and over time it becomes easier to form the pattern of "the more important it is, the harder it is to approach" |
| Inner Impact | Anxiety mixed with mild self-reproach; action energy gets split, and unresolved safety debt accumulates internally |
| Outer Impact | Core responsibilities move more slowly, which can affect commitments, pace, and credibility |
| Rigidity / Choice | Moderately high; not pure paralysis, but there is a clear automatic slide away from the main task |
| Value Alignment | Relatively low; it preserves some local freedom, but does not fit the value of actually moving meaningful responsibilities forward |
| Short-Term Intervention Point | `Safety and Threat Avoidance`, environment level |
| Long-Term Restructuring Focus | `Competence and Efficacy`, `Safety and Threat Avoidance` |
| Long-Term Restructuring Path | First reduce the threat level and granularity of the main task, then gradually build experiences of approaching important work safely, and finally shift competence back from preferred side tasks into the real core task |

One-line version:

This is not just "laziness." It is closer to high-priority work triggering safety pressure, which then makes the system grab toward side tasks that feel safer, sweeter, and more self-directed.

## Case: Short-Form Videos / Nonsense Videos

| Field | Content |
| --- | --- |
| Behavior | Scrolling short-form videos or watching nonsense videos in a way that lets the person hang themselves inside fragmented content |
| Trigger Context | More likely to activate during waiting, uncertainty, blankness, boredom, stress, stuckness, or any moment when the person does not want to directly face the present |
| Basic Dimensions | Mainly `Safety and Threat Avoidance`; secondarily `Rest and Recovery`, though often in the form of pseudo-recovery |
| Higher-Order Dimensions | `Exploration and Understanding` gets hijacked; sometimes there is also a very weak trace of `Autonomous Agency` |
| Reaction Channel(s) | Often begins with `Fear / Avoidance`, then slides into `Freeze / Shutdown` |
| Source | `mixed` |
| Intensity | Moderate; not necessarily overwhelming every time, but the activation threshold is very low |
| Higher-Order Hijack / Organization | `Exploration and Understanding` gets hollowed out into low-cost, fragmented novelty. Sometimes a weak form of `Autonomous Agency` joins in as "I am choosing to watch something light first" |
| Basic-Dimension Landing / Lower-Level Hijack | The real landing point is still `Safety and Threat Avoidance` plus `Rest and Recovery`: the system wants to step away from discomfort and uncertainty, then mistakes fragmented stimulation for restoration, producing pseudo-rest |
| Short-Term Gain | Less blankness, less waiting, faster passage of time, and the feeling that one has "rested a little" |
| Long-Term Cost | Real recovery does not actually happen, attention gets fragmented, returning to meaningful work gets harder, and the original safety debt remains unpaid |
| Inner Impact | Numbing, dulling, pseudo-relief, fractured attention, and more passive state-shifting |
| Outer Impact | Time gets swallowed, responsibilities stall, and important things remain suspended for longer |
| Rigidity / Choice | Moderately high; the entry is easy and the reward is fast, so it is easy to slide into automatically |
| Value Alignment | Relatively low; it offers temporary refuge, but usually does not fit the longer life one wants to live |
| Short-Term Intervention Point | environment level, reaction-channel level |
| Long-Term Restructuring Focus | `Safety and Threat Avoidance`, `Rest and Recovery` |
| Long-Term Restructuring Path | First reduce the availability and frictionless access of fragmented stimuli, then relearn the difference between real recovery and pseudo-recovery, and finally build more tolerance for uncertainty and blankness without immediately fast-forwarding out of them |

One-line version:

This is usually less "I truly want these videos" and more "I cannot bear this moment, so I use a chain of tiny, light, fast stimuli to remove myself from reality a little."

## Plain-Language Read

If you step away from the table format, these two examples are pointing to something simple:

- A lot of procrastination is not "I do not want to move at all." It is "I do not want to touch the thing that might expose me, dominate me, or settle the answer."
- A lot of short-video use is not just "I am being lazy or playful." It is "I do not want to stay inside this blank, stuck, uncomfortable, unresolved moment."
- In both cases, the system is still regulating. It is just doing so by grabbing the fastest, lightest, lowest-friction substitute path it knows.

That is why these two examples are useful starter demonstrations:

- They show how the framework separates surface behavior from underlying drivers.
- They show how "laziness" can break down into `safety pressure + avoidance channel + higher-order hijack`.
- They show how video-scrolling can break down into `safety avoidance + pseudo-recovery + hijacked exploration`.
- They show why the answer is not just "push harder" or "blame self-control," but first asking what the system is avoiding and what it is mistakenly using as recovery.
