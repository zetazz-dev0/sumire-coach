# Behavior Analysis Framework

## Purpose

- This document records the current working model for analyzing behavior problems.
- It provides four tables that work together:
  - Basic Dimensions
  - Higher-Order Dimensions
  - Reaction Channels
  - Behavior Profile
- This is a working document, not a claim of final theory.

## Core Principles

- "Original" does not mean it should be satisfied without limit.
- "Internalized" does not mean it should all be removed.
- This framework is primarily an internal analysis tool. It is not meant to be dumped wholesale into the user's experience during ordinary coaching.
- Most concrete behaviors are co-produced by several layers:
  - basic dimensions
  - higher-order dimensions
  - reaction channels
  - later internalized scripts
- Basic dimensions are closer to bodily necessity, so they are analyzed more finely.
- Higher-order dimensions are not "farther away" from the lower layer. They are organized, extended, and compounded structures built on lower-level needs, so they are mainly for reference and explanation rather than ultra-fine breakdown.
- A reaction channel is not a need and not a concrete behavior. It is the output path the system tends to choose when a need is blocked, threatened, or dysregulated.
- A single behavior may involve multiple reaction channels, and those channels may also appear in sequence.
- When analyzing a "hijack" relationship, it is usually cleaner to do it in layers: first ask whether the behavior borrows a higher-order dimension, then ask where it finally lands in the basic layer.
- In practice, many conclusions should first be treated as working hypotheses. If uncertainty remains, use follow-up questions to confirm the weak links and revise the analysis accordingly, rather than locking in a conclusion too early.

## Internal Use and Storage

- By default, this framework should operate in the background rather than become the visible structure of the conversation.
- The coach should usually use the framework to organize notes, track hypotheses, and update pattern understanding over time.
- Durable analysis should be stored and updated in the memory system:
  - `sumire_notes/` for session-specific observations, working hypotheses, and recent changes
  - `user_overall.md` for cross-session pattern understanding that has become stable enough to matter
  - `people/` for person-specific patterns, dynamics, and recurring interpretations
- When a behavior pattern has begun to show a usable shape, create or update a working profile in `behavior-analysis-records/` rather than waiting for full clarity.
- Keep the memory files as the summary layer, and keep the fuller structured worksheet in `behavior-analysis-records/`.
- Use one file per recurring behavior pattern. Revise the existing record when the picture changes instead of leaving outdated versions to coexist without clarification.
- When the user clarifies, corrects, or updates the picture, the stored analysis should be revised accordingly rather than left frozen.
- In this repository, user-specific records in `sumire_notes/`, `user_overall.md`, `people/`, and `behavior-analysis-records/` are written in Japanese. If private asides appear, follow the same private-aside rule used by the other private records.
- In the actual coaching conversation, prefer plain, ordinary language and gentle guidance. Avoid exposing professional jargon unless the user explicitly wants the theory, the schema, or the documentation layer.

## Usage Boundary (Note)

- This framework is better suited for complex, recurring problems than for small problems where the next action is already obvious.
- It is usually more helpful when a problem keeps recurring, when surface explanations are not enough, when the person already "knows what to do" but still cannot do it, or when the same behavior simultaneously involves the body, relationships, and self-worth.
- If the problem is already straightforward, such as lack of sleep, obvious environmental distraction, a task not yet broken down, or simply "I do not want to do this today and the cost is low," then directly handling the practical issue is usually better than running the full framework.
- A practical test is this: if the framework changes how you would intervene, it is useful; if it only increases interpretive pleasure without changing action, it is probably overcomplicating a simple problem.

## Practice Note: Use Follow-up Questions to Confirm Uncertain Conclusions

- Many judgments in behavior analysis, especially `Trigger Context`, `Higher-Order Hijack / Organization`, `Reaction Channel`, `Short-Term Gain`, and `Long-Term Cost`, are only working hypotheses on first pass.
- When one conclusion has multiple plausible explanations, or when the analyst is unsure about a link in the chain, do not force a conclusion. Use follow-up questions to confirm the uncertain parts, and adjust the analysis based on the answers.
- The point of follow-up questions is not to make the analysis longer. It is to reduce misreading and avoid treating the analyst's guess as the user's real structure.
- Common areas that often need follow-up confirmation include:
  - what actually triggers the behavior
  - whether a higher-order dimension is really being borrowed, or whether the behavior directly hits the basic layer
  - whether the short-term gain is relief, avoidance, being seen, restored control, or something else
  - whether the reaction channel is singular, mixed, or sequential
  - whether the long-term cost is mainly internal, mainly external, or both
- In practice, this framework usually needs to be paired with follow-up questions, and the analysis should be revised according to confirmed information rather than treated as finished after one pass.

## History-Aided Higher-Order Exploration

- Higher-order exploration should not rely only on whatever the user happens to self-generate in the current turn.
- Before asking higher-order questions, it is often useful to review the user's accumulated history — for example the overall profile, recent notes, and relevant person history — to spot themes that recur across time.
- Common higher-order themes may include:
  - autonomy
  - competence
  - being seen or needed
  - dignity or position
  - connection to the world
  - meaning
  - identity continuity
- These are not conclusions. They are prompts for better questions.
- In live conversation, explore them in ordinary language. For example:
  - what feels hardest to put down here
  - what this behavior may be helping the person keep hold of
  - what it lets the person stay connected to
  - what it seems to prove, preserve, or protect
  - what, if anything, is truly left behind after the behavior is over

## Soft Entry And Early Working Profiles

- With unfamiliar users, or with a newly surfaced problem, start with a soft entry rather than immediate structure.
- A good order is:
  1. one recent, concrete moment
  2. what the behavior helped with in that moment
  3. what felt harder to lose, put down, or disconnect from
- Do not start a structured record at first mention.
- Start a working profile once the pattern has a usable early shape — for example, a recognizable behavior object plus some combination of trigger, short-term function, higher-order hint, or reaction pattern.
- The record does not need to be complete. It needs to be revisable.
- The point is to begin externalizing the pattern once it is real enough to track, then keep refining it as the user adds, corrects, or deepens the picture.

## I. Basic Dimensions

Notes:

- The basic layer keeps only two top-level categories:
  - physiological needs
  - safety needs
- This layer is the first landing point because it is closest to the body's and the system's basic functioning.

### 1. Physiological Needs

| Dimension | Core Need | Native Signal | Common Hijack Pattern |
| --- | --- | --- | --- |
| Physiological Maintenance | Food, water, elimination, temperature regulation, pain avoidance | Hunger, thirst, pressure, pain, discomfort from heat or cold | Emotional eating, using food or drink to numb oneself |
| Rest and Recovery | Sleep, shutdown, rhythm restoration | Tiredness, dullness, emptiness, sore eyes, wanting to lie down | Revenge bedtime procrastination, mistaking numbing-out for rest |
| Sexuality and Physical Intimacy | Arousal, touch, pleasure, bodily merging | Sexual arousal, wanting to touch or be touched, fantasy, wanting bodily soothing | Dependence on specific scripts, button-based stimulation, shame-bound sexual loops |

### 2. Safety Needs

| Dimension | Core Need | Native Signal | Common Hijack Pattern |
| --- | --- | --- | --- |
| Safety and Threat Avoidance | Reduce danger and uncertainty; maintain predictability and defendability | Tension, vigilance, repeated checking, wanting to avoid, fear of losing control | Compulsive checking, overcontrol, order obsession |
| Anti-Intrusion Boundary | Not being invaded, controlled, or crossed | Wanting to say no, wanting to push back, resisting being arranged, wanting to re-establish lines | Over-defensiveness, extreme self-reliance, reactance, controlling others |

## II. Rating Axes for Basic Dimensions

Notes:

- The rating target is the dimension itself, not a specific behavior.
- A `0-5` scale is recommended throughout.
- These ratings mainly support later behavior-profile analysis.

### 1. Baseline Intensity

Definition: how active this basic dimension tends to be in relatively neutral conditions, without obvious deprivation and without strong external stimulation.

| Score | Meaning |
| --- | --- |
| 0 | Almost never activates on its own; barely noticeable in ordinary life |
| 1 | Activates lightly on occasion; low presence |
| 2 | Relatively low, but shows up in fitting contexts |
| 3 | Moderate and steadily present |
| 4 | Relatively high; often comes online on its own |
| 5 | Very high; noticeably active even in ordinary conditions |

### 2. Deprivation Pain

Definition: how much distress, pain, or dysregulation appears when this dimension is not adequately met for an extended period.

| Score | Meaning |
| --- | --- |
| 0 | Little to no felt cost when unmet |
| 1 | Mild discomfort, small impact |
| 2 | Clearly uncomfortable, but usually still manageable |
| 3 | Persistent enough to pull attention and affect state |
| 4 | Strong pain, likely to affect functioning or emotional stability |
| 5 | Very strong pain, likely to produce major dysregulation, collapse, or compensatory behavior |

### 3. Hijackability

Definition: how easily this basic dimension gets "borrowed" by later scripts, habits, identities, shame structures, reward loops, and similar mechanisms.

| Score | Meaning |
| --- | --- |
| 0 | Hard to hijack; original need and later script are easy to distinguish |
| 1 | Occasionally pulled off course, but still mostly clear |
| 2 | Hijacked in specific contexts |
| 3 | Hijacking is fairly common and needs active discrimination |
| 4 | Easily hijacked; once activated, it often falls into a fixed path |
| 5 | Extremely hijackable; original need and later script are almost fused |

## III. Notes on Using the Ratings

- `Baseline Intensity` answers: how strong is this dimension by default?
- `Deprivation Pain` answers: how painful is it when this dimension remains unmet?
- `Hijackability` answers: how easily does it get borrowed by other structures?

Do not collapse these into one thing. For example:

- a dimension can have high `Baseline Intensity` but low `Hijackability`
- it can have modest `Baseline Intensity` but high `Deprivation Pain`
- it can have ordinary `Baseline Intensity` but extremely high `Hijackability`

## IV. Higher-Order Dimensions (Reference)

Notes:

- Higher-order dimensions are not "less important." They are more compounded.
- They are usually organized, extended, or compounded from lower-level needs.
- This layer is mainly for reference and explanation; it does not need the same granularity as the basic layer.

| Higher-Order Dimension | Current Understanding |
| --- | --- |
| Attachment and Bonding | A compounded structure organized from safety, sexuality, and co-regulation experience |
| Recognition and Social Position | A compounded structure involving safety, status, self-preservation, and social place |
| Competence and Efficacy | A compounded structure involving safety, control, resource-acquisition ability, and felt worth |
| Autonomous Agency | A structure of self-direction and authorship of one's life built on sufficient safety |
| Exploration and Understanding | Active movement toward the unknown, knowledge, the world, and the self |
| Creation and Expression | The tendency to organize inner material into works, forms, or expression |
| Meaning and Transcendence | The tendency to seek meaning, direction, and things beyond immediate self-interest |
| Care and Contribution | The tendency to direct one's ability, resources, and attention toward others, groups, or the world |

## V. Reaction Channels (v1)

Notes:

- A reaction channel is not a need and not a concrete behavior.
- It is better understood as the output path the system prefers when a need is blocked, threatened, or dysregulated.
- The same blocked need may produce different channels; the same channel may produce many behaviors.
- A single behavior may also involve multiple reaction channels, for example: avoid first, then freeze; or protest while also feeling fear.
- For this reason, anger is no longer treated as an independent dimension here. It is treated as a reaction channel.

| Reaction Channel | Core Function | Body Feel | Common Behavioral Output |
| --- | --- | --- | --- |
| Overaction / Getting Things Done | Maintain control by continuing to act; avoid touching helplessness, blankness, or loss of control | Holding tension, bracing, carrying a charge, panic when stopping | Making lists, continuing to work, endless optimization, busily solving, inability to stop |
| Anger / Counter-Push | Push obstacles away, restore force, reclaim agency | Heat, forward drive, tightening, urge to move against something | Arguing back, attacking, controlling, rebutting, pushing away |
| Fear / Avoidance | Reduce threat and move away from risk | Coldness, tightness, vigilance, urge to shrink back | Hiding, delaying, escaping, repeated checking, not touching the issue |
| Pursuit / Protest | Pull connection, response, or the object back | Agitation, tugging, urge to contact immediately | Pursuing, explaining, clinging, seeking reassurance, jealousy |
| Sadness / Withdrawal | Acknowledge loss, stop fighting, move into grief | Heaviness, softness, sinking, urge to cry | Pulling back, stopping, sinking down, giving up the struggle |
| Freeze / Shutdown | Shut down under overload to reduce further damage | Emptiness, numbness, disconnection, blank mind | Staring out, spacing out, collapsing, getting stuck and not moving |
| Submission / Appeasing | Stay safe under power asymmetry by securing safety through compliance | Softness, strained smile, tension, not daring to resist | Apologizing, accommodating, agreeing, orienting around the other |

## VI. Behavior Profile

| Field | Meaning |
| --- | --- |
| Behavior | The concrete pattern being analyzed |
| Trigger Context | The situations, pressures, blanks, or relationship climates that usually activate the pattern |
| Basic Dimensions | Which basic dimensions are involved |
| Higher-Order Dimensions | Which higher-order dimensions are involved, if any |
| Reaction Channel(s) | If the behavior is reactive, which output path(s) it primarily uses, and whether there is sequence or mixture |
| Source | More original-layer, internalized-layer, or mixed |
| Intensity | How strong the driving force is |
| Higher-Order Hijack / Organization | Which higher-order dimensions the behavior borrows or organizes around, if any, such as competence, recognition, attachment, or exploration |
| Basic-Dimension Landing / Lower-Level Hijack | Which basic dimensions are consumed, suppressed, compensated for, or otherwise affected either directly or through the higher-order hijack |
| Short-Term Gain | What the pattern immediately delivers |
| Long-Term Cost | What the pattern costs over time |
| Inner Impact | Bodily cost, anxiety, depletion, numbness, pleasure, and related internal effects |
| Outer Impact | Effects on relationships, environment, responsibility, or social context |
| Rigidity / Choice | Whether the pattern can be delayed, replaced, or not enacted at all |
| Value Alignment | Whether the pattern still fits the kind of life the person wants to live |
| Short-Term Intervention Point | Where to intervene first in order to stabilize things, reduce damage, and create some choice space |
| Long-Term Restructuring Focus | The deeper structure that would need to change in order to reduce recurrence or loosen the pattern for real |
| Long-Term Restructuring Path | The longer sequence or direction for gradually restructuring the pattern |

### On Layered Hijack Analysis

- `Higher-Order Hijack / Organization` answers: why does this behavior feel meaningful enough for the system to keep running it?
- Common higher-order borrowed structures include `Competence and Efficacy`, `Recognition and Social Position`, `Attachment and Bonding`, `Autonomous Agency`, and `Exploration and Understanding`.
- `Basic-Dimension Landing / Lower-Level Hijack` answers: where does this behavior finally land, where does it soothe, where does it wound, and who ultimately pays the cost?
- Common landing points include `Safety and Threat Avoidance`, `Rest and Recovery`, `Physiological Maintenance`, `Anti-Intrusion Boundary`, and `Sexuality and Physical Intimacy`.
- Not every case contains a higher-order hijack. Some behaviors hit the lower layer directly.
- So the cleaner sequence is usually:
  - first ask whether anything higher-order is being borrowed
  - then ask which basic dimension it finally lands on

A compact sentence template:

`This behavior borrows which higher-order dimension, and ultimately lands on which basic dimension?`

### On Short-Term Intervention Point / Long-Term Restructuring Focus / Long-Term Restructuring Path

- `Short-Term Intervention Point` answers: where should you move first to stabilize, reduce cost, and create a bit of choice?
- `Long-Term Restructuring Focus` answers: what deeper structure ultimately needs to change?
- `Long-Term Restructuring Path` answers: how do you plan to change it, and in what order?
- These three answers do not need to be the same.
- A common pattern looks like this:
  - short term: stabilize a reaction channel or the environment
  - long term: change the binding pattern around a higher-order or basic dimension
- In other words, these three fields answer:
  - where to stabilize first
  - what ultimately needs to change
  - how the change will be approached

## VII. Suggested Workflow

1. Clarify the behavior itself.
2. Identify the context in which it usually gets activated.
3. Identify the basic dimensions involved.
4. Check whether any higher-order dimensions are also involved.
5. Ask whether the behavior borrows a higher-order dimension; if yes, describe how.
6. Then ask where it finally lands in the basic layer; if there is no clear higher-order hijack, you can go directly to the lower-level landing.
7. If it is reactive, identify the main reaction channel(s), including mixture or sequence.
8. Judge whether the pattern is more original-layer, internalized-layer, or mixed.
9. Use follow-up questions to confirm uncertain parts, and revise the analysis accordingly rather than rushing to conclusion.
