# Behavior Analysis Records

- This directory stores fuller structured behavior-analysis profiles.
- Use one file per recurring behavior pattern.
- Update the existing file when the picture changes; do not let old conclusions linger without revision notes.
- Keep `sumire_notes/`, `user_overall.md`, and `people/` as the summary/memory layer.
- Use this directory for the fuller worksheet/profile when a behavior has been analyzed in enough detail to justify one.
- In this repository, user-specific profiles in this directory should be written in Japanese. If private asides are used, follow the same private-aside rule as the other private records.
